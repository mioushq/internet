06 / ZASADY

Reguły systemu

Sześć zasad, które trzymają liquid-glass w ryzach.

1 · Głębia przez warstwy

z-stack
Warstwy: Tło (radialne gradienty + ziarno) → Orby (blur 80px, drift) → Glass (blur 18-24px, alpha .04-.08) → Treść. Nigdy nie zatrzymujemy się na płaskim kolorze.

2 · Akcent = jeden CTA

magenta only
Magenta jest wyłącznie dla jednej akcji konwersyjnej na ekranie (Szukaj, Zamów, Zobacz ofertę). Cyjan dla informacji i statusów. Fiolet jako fundament marki.

3 · Pill, nie prostokąt

border-radius:999
Wszystkie elementy interaktywne — przyciski, chipy, badge'e, search — mają zaokrąglone końce. Karty zachowują 16-24px. Inputy i kbd: 6-10px.

4 · Highlight zawsze inset

inset 0 1px 0
Każda glass-surface dostaje inset 0 1px 0 rgba(255,255,255,.1-.3) — to imituje refleks światła. Bez tego powierzchnia wygląda płasko.

5 · Ruch jest dyskretny

20-28s drift
Tło żyje (orby), ale powoli (22-28s). Akcenty pulsują (2s). Hover = translateY(-1 do -3px). Nigdy nie strząsamy treści — animacja podkreśla, nie krzyczy.

6 · Treść > dekoracja

copy first
Konkretne liczby (8 Gb/s, 49 zł, <5ms) zawsze wygrywają z abstrakcyjnymi pojęciami. Mono dla danych, Sora dla emocji, Manrope dla czytania.
